Ultra LoRA Reference Images 사용자 메뉴얼 v2
패키지: comfyui-Ultra-LoRA-Reference-Images
============================================================

`🎴 Ultra LoRA Reference Images`는 Qwen Image Edit 2511 또는 Qwen Image 2.1을 사용해 인물 LoRA 학습용 레퍼런스 PNG와 같은 이름의 TXT 캡션을 자동 생성·저장하는 ComfyUI 커스텀 노드입니다.

외부 MODEL / CLIP / VAE 로더를 별도로 연결하지 않아도 되며, 모델 파일과 LoRA를 노드 내부에서 선택할 수 있습니다.


======================================================================
1. 빠른 시작
======================================================================

1. `예제/Ultra-LoRA-Reference-Images.json`을 ComfyUI에 불러옵니다.
2. 얼굴 참조 이미지를 선택합니다.
3. 밸런스 모드를 사용할 경우 같은 인물의 두 번째 참조 이미지를 선택합니다.
4. `모델 계열`에서 `Qwen Image Edit 2511` 또는 `Qwen Image 2.1`을 선택합니다.
5. `모델 설정`을 펼쳐 Diffusion Model / Text Encoder / VAE를 선택합니다.
6. 필요한 경우 `LoRA 설정`을 펼쳐 LoRA를 추가합니다.
7. 생성 모드, 장수, 조명, 의상, 배경, 표정 등의 옵션을 선택합니다.
8. Queue를 실행합니다.

결과 폴더
  ComfyUI/output/lora_dataset/<실행 폴더>/

각 PNG와 같은 이름의 TXT 캡션이 함께 저장됩니다.

[권장 기본 초기값]
- 트리거 토큰: 비어 있음
- 피사체 설명: a korean woman
- 생성 모드: 얼굴전용
- 이미지 수: 24
- 조명 옵션: 안정적분산
- 의상 다양성: 보통
- 배경 옵션: 단순
- 표정 변화: 보통
- 정체성 보존: 균형
- Seed: 0 / 생성 후 제어: randomize
- Steps: 8 / CFG: 1.0
- Sampler: euler / Scheduler: simple / Denoise: 1.0
- 출력 비율: 원본 비율
- 모델 계열: Qwen Image Edit 2511

새 노드를 처음 삽입했을 때 위 값을 기본으로 사용합니다. 모델별 마지막 사용 설정이 이미 저장된 환경에서는 해당 기억값이 모델 전환 시 다시 복원될 수 있습니다.


======================================================================
2. 참조 이미지 준비
======================================================================

[얼굴전용]
- 얼굴 참조 이미지 1장이 필요합니다.
- 얼굴 정체성, 헤어, 얼굴 각도·표정·시선 분산에 초점을 둡니다.
- 24 / 30 / 40장 모두 얼굴 중심 구도입니다.
- 얼굴전용에서는 의상을 적극적으로 교체하지 않습니다. 참조 이미지의 의상은 얼굴 데이터셋의 주된 변화 대상이 아닙니다.

[밸런스]
- 같은 인물의 이미지 2장이 필요합니다.
- 권장 조합:
  1) 얼굴이 선명한 얼굴 참조 이미지
  2) 상반신~허벅지 위가 자연스럽게 보이는 밸런스 참조 이미지

밸런스 입력의 역할은 몸 비율·어깨 폭·프레이밍 기준을 보충하는 것입니다.

상반신 이미지가 없다면 같은 인물의 얼굴 이미지 2장을 각각 연결해도 아무 문제 없이 실행됩니다. 노드는 이미지가 얼굴 사진인지 상반신 사진인지 검사해서 차단하지 않습니다. 다만 얼굴 이미지 2장만 사용할 경우 실제 상반신 참조보다 체형·어깨 폭·전신 프레이밍 정보가 적기 때문에 몸 구도의 안정성이 조금 낮을 수 있습니다.

얼굴 참조와 밸런스 참조는 반드시 같은 인물을 사용하십시오. 서로 다른 인물을 연결하면 얼굴·헤어·체형 정보가 섞일 수 있습니다.

밸런스 모드는 얼굴, 상반신, 허벅지 위, 전신을 섞습니다.

24장: 얼굴 9 / 상반신 7 / 허벅지 위 5 / 전신 3
30장: 얼굴 11 / 상반신 9 / 허벅지 위 6 / 전신 4
40장: 얼굴 14 / 상반신 12 / 허벅지 위 8 / 전신 6


======================================================================
3. 의상 다양성
======================================================================

의상 다양성은 밸런스의 상반신·허벅지 위·전신 변형에서 실제로 사용됩니다.

낮음
- 4종의 비교적 단순한 의상 후보를 순환합니다.
- 의상 변화보다 인물 자체를 안정적으로 학습하고 싶을 때 적합합니다.

보통
- 8종 후보를 사용합니다.
- 일반적인 인물 LoRA 데이터셋에 권장되는 균형값입니다.

높음
- 12종 후보를 사용합니다.
- 의상 고착을 더 줄이고 다양한 복장을 섞고 싶을 때 사용합니다.

중요
- 밸런스 몸 변형에서는 참조 이미지의 의상을 정체성 요소로 취급하지 않습니다.
- 참조 이미지에 보이는 옷을 그대로 복제하지 않고, 각 변형에 계획된 새 의상을 우선하도록 내부 프롬프트가 지시합니다.
- 얼굴·헤어·몸 비율 기준은 유지하면서 의상만 변화시키는 것이 목적입니다.
- 얼굴전용과 밸런스의 얼굴 클로즈업은 의상 교체 지시를 사용하지 않습니다.

따라서 얼굴 데이터는 불필요한 의상 변화에 끌려가지 않고, 밸런스 몸 데이터에서만 의상 다양성 옵션이 실제 의미를 갖습니다.

4. 주요 생성 옵션
======================================================================

[생성 모드]
- 얼굴전용: 얼굴 중심 데이터셋
- 밸런스: 얼굴 + 상반신 + 허벅지 위 + 전신 데이터셋

[이미지 수]
- 24 / 30 / 40

[조명 옵션]
- 사용안함
- 안정적분산
- 다양한분산

[배경 옵션]
- 단순
- 실내실외혼합
- 다양화

[표정 변화]
각 변형의 프롬프트에 표정이 직접 지정됩니다. 낮음/보통/높음에 따라 사용되는 표정 후보 풀이 넓어집니다.

[정체성 보존]
- 강함
- 균형
- 자유

참조 이미지를 직접 사용하는 편집 모델이므로 정체성은 기본적으로 강하게 작용합니다. 일반적인 데이터셋에서는 `균형`을 권장합니다.

[출력 비율]
- 원본 비율
- 자동 구도별 비율

[Seed / Steps / CFG / Sampler / Scheduler / Denoise]
일반 ComfyUI 샘플링 설정입니다. 모델 계열을 2511 ↔ 2.1로 전환해도 이 값들은 자동 변경하지 않습니다.


======================================================================
5. 모델 계열과 내부 모델 설정
======================================================================

노드의 `모델 설정`은 기본적으로 접혀 있습니다. 펼치면 현재 모델 계열에 필요한 모델 파일만 표시됩니다.

Qwen Image Edit 2511
- Diffusion Model
- Text Encoder
- VAE

Qwen Image 2.1
- Diffusion Model
- Text Encoder
- VAE
- Cache device
- Cache dtype

2511과 2.1의 모델 관련 설정은 서로 별도로 기억됩니다. 같은 브라우저 프로필에서는 설정을 변경하면 즉시 마지막 사용 설정으로 기록되며, 워크플로우를 저장하지 않고 ComfyUI를 종료하더라도 브라우저 localStorage가 유지되는 한 다음 실행에서 복원됩니다.

워크플로우를 저장하면 해당 워크플로우의 값도 함께 저장됩니다.

Steps / CFG / Sampler / Scheduler / Denoise / Seed 같은 일반 생성값은 모델별 마지막 사용 기억 대상이 아닙니다.


======================================================================
6. LoRA 설정
======================================================================

`LoRA 설정`을 펼쳐 현재 모델 계열에 사용할 LoRA를 관리합니다.

- `LoRA 추가`: 새 LoRA 행 추가
- 활성/비활성: 실행 적용 여부
- 강도: LoRA strength
- 위로/아래로 이동: 실제 MODEL 적용 순서 변경
- 삭제: 해당 행 제거

2511과 2.1의 LoRA 목록은 서로 섞이지 않습니다. 각 모델 계열마다 파일명, 순서, 강도, 활성 상태를 따로 기억합니다.

2511용 LoRA를 2.1에 그대로 사용하는 것은 권장하지 않습니다. 각 모델 계열에 맞는 LoRA를 선택하십시오.


======================================================================
7. 내부 처리 흐름 - Qwen Image Edit 2511
======================================================================

사용자는 아래 내부 노드를 따로 배치할 필요가 없습니다. 참고용 설명입니다.

1. 선택한 2511 Diffusion Model 로드
2. 활성 LoRA를 표시 순서대로 MODEL에 적용
3. CFGNorm을 strength 1.0으로 내부 자동 적용
4. `TextEncodeQwenImageEditPlus`로 편집 conditioning 생성
5. 참조 이미지와 `VAEEncode` / `FluxKontextMultiReferenceLatentMethod`를 이용해 2511용 reference latent 구성
6. KSampler 실행
7. VAE Decode
8. PNG와 TXT 캡션 저장

CFGNorm은 사용자 UI에 노출하지 않습니다. 2511에서 내부 자동 처리되며 Qwen Image 2.1에서는 사용하지 않습니다.


======================================================================
8. 내부 처리 흐름 - Qwen Image 2.1
======================================================================

1. 선택한 Qwen Image 2.1 Diffusion Model 로드
2. 활성 LoRA를 표시 순서대로 MODEL에 적용
3. `QwenImage21Cache` 적용
4. `TextEncodeQwenImage21`에서 positive / negative / 시작 latent 생성
5. KSampler 실행
6. VAE Decode
7. PNG와 TXT 캡션 저장

2.1은 2511의 `TextEncodeQwenImageEditPlus`, `FluxKontextMultiReferenceLatentMethod`, CFGNorm 경로를 사용하지 않습니다.

얼굴 변형
- 얼굴 참조 이미지 1장을 2.1 전용 conditioning에 사용합니다.

밸런스의 상반신·허벅지 위·전신 변형
- image1 = 밸런스 참조 이미지: 몸 비율·프레이밍 기준
- image2 = 얼굴 참조 이미지: 얼굴 정체성·헤어 기준

밸런스의 얼굴 클로즈업 변형
- 얼굴 참조 이미지 1장만 사용합니다.

두 입력 모두 얼굴 이미지여도 실행에는 문제가 없습니다. 다만 image1에 실제 상반신 이미지가 있으면 몸 비율·프레이밍 기준이 더 풍부합니다.

2.1에서는 CFGNorm을 사용하지 않습니다.

10. 설치 / 업데이트 / 제거
======================================================================

설치 위치
  ComfyUI/custom_nodes/comfyui-Ultra-LoRA-Reference-Images/

설치
1. ComfyUI를 완전히 종료합니다.
2. ZIP을 위 위치에 설치합니다.
3. 폴더 바로 아래에 `__init__.py`, `reference_images.py`, `web`, `locales`, `예제`가 보여야 합니다.
4. ComfyUI를 실행합니다.

업데이트
1. ComfyUI를 완전히 종료합니다.
2. 기존 `comfyui-Ultra-LoRA-Reference-Images` 폴더를 삭제합니다.
3. 새 버전을 설치합니다.
4. ComfyUI를 다시 실행합니다.

제거
- ComfyUI를 종료하고 해당 custom_nodes 폴더를 삭제합니다.
- 이미 생성된 `ComfyUI/output/lora_dataset/`의 PNG/TXT는 삭제되지 않습니다.

11. 문제 해결
======================================================================

[노드가 빨간 테두리로 표시됨]
- ComfyUI를 완전히 종료한 뒤 기존 노드 폴더를 삭제하고 새 버전을 다시 설치하십시오.
- 같은 패키지를 다른 이름의 폴더로 중복 설치하지 마십시오.
- `모델 설정`을 펼쳐 현재 설치되어 있는 실제 모델 파일을 다시 선택하십시오.

[밸런스 모드가 실행되지 않음]
- 두 번째 밸런스 이미지 입력이 연결되어 있는지 확인하십시오.
- 밸런스 모드는 사용자가 두 번째 입력을 직접 연결해야 합니다.

[의상이 참조 이미지와 너무 비슷함]
- 밸런스 몸 변형은 참조 의상을 복제하지 않도록 내부 프롬프트가 지정되어 있습니다.
- `의상 다양성`을 보통 또는 높음으로 사용해 보십시오.
- 얼굴전용에서는 의상 교체가 주목적이 아니므로 참조 의상이 유지되는 것이 자연스럽습니다.

[모델 계열 전환 후 설정]
- 2511과 2.1의 모델·LoRA 설정은 계열별로 별도 기억됩니다.
- 같은 브라우저 프로필의 localStorage를 삭제하면 마지막 사용 기억도 초기화될 수 있습니다.

[첫 생성 이미지가 바로 보이지 않음]
- 최신 버전은 실행 완료 후 ComfyUI canvas preview redraw를 보강합니다.
- 계속 문제가 있으면 브라우저 콘솔과 ComfyUI 콘솔 오류를 확인하십시오.


======================================================================
12. 데이터셋 사용 전 확인
======================================================================

자동 생성 결과는 학습 전에 직접 확인하는 것을 권장합니다.

확인 항목
- 얼굴이 같은 인물로 유지되는가
- 손·팔·다리 등 신체가 심하게 깨진 이미지가 없는가
- 상반신/전신 구도가 잘리지 않았는가
- 의상 변화가 필요한 밸런스 몸 이미지에서 참조 의상에 과도하게 고정되지 않았는가
- TXT 캡션이 실제 이미지 내용과 크게 다르지 않은가

문제가 있는 PNG/TXT 쌍은 학습 데이터에서 제외하거나 캡션을 직접 수정하십시오.
